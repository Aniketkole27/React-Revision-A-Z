# React A→Z Revision ⚛️

A concise but complete, phase-by-phase revision guide covering React from the absolute basics to advanced, modern, and interview-level concepts. Each phase is a self-contained Markdown file with a table of contents, explanations, code examples, a quick-revision summary, and interview-style questions.

Whether you're refreshing your React knowledge before an interview or building a structured mental map of the library, this repo is designed to be read top to bottom or dipped into topic by topic.

- **📚 Contents** — jump straight to the topic you need

- **Quick Revision** — a fast summary for last-minute review
- **Interview Revision / Questions** — commonly asked questions with concise answers

## 🧭 How to Use This Repo

- **Studying from scratch?** Go phase by phase, starting with `01-React-Fundamentals.md`.
- **Revising before an interview?** Jump to the *Quick Revision* and *Interview Questions* sections at the end of each file, or go straight to `14-Interview Concepts.md`.
- **Looking up a specific topic?** Use the table above or the per-file table of contents to jump directly to it.
